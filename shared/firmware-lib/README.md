# shared/firmware-lib

Briques C++ réutilisables entre projets embarqués : touch capacitif, LED REC,
BLE, OTA, deep sleep. Consommé par `skald/firmware/` et les futurs projets.

Stack : C++ / PlatformIO / Arduino Core ESP32. Tests : Unity ou GoogleTest.
