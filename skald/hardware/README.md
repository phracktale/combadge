# skald/hardware

Schémas PCB, fichiers STL, BOM du device Skald.

Carte : Seeed XIAO ESP32-S3 Sense. LED REC SMD 0805 + 470 Ω. Touch capacitif
natif. LiPo 502025 200 mAh + BMS. BOM v1 indicative ~22 €.

Stack : KiCad / Fusion 360. Réutilise `shared/hardware-templates/`.
