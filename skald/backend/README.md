# skald/backend

API REST d'ingestion, gestion de l'archive, administration. Communication
device → backend en HTTP REST (v0.1), Mercure en v0.2+.

Stack : Symfony 7 / PHP 8.2 / EasyAdmin 4 / API Platform 4 / Doctrine /
PostgreSQL 16 + pgvector. Tests : PHPUnit.

Réutilise `shared/backend-bundle/`.

> Dossier en attente d'implémentation. Voir `docs/architecture.md`.
